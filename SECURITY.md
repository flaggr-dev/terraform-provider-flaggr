# Security Policy

Please don't report security vulnerabilities in public GitHub issues.

Email **[security@flaggr.dev](mailto:security@flaggr.dev)** with a description of the issue, steps to reproduce it and its potential impact. We acknowledge reports within 48 hours and coordinate disclosure with you once a fix is available.

This policy covers this provider and the Flaggr platform at [flaggr.dev](https://flaggr.dev).

## Supported versions

Security fixes are released for the latest minor version of the provider.
