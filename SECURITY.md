# Security Policy

Please don't report security vulnerabilities in public GitHub issues.

Report them privately, either through GitHub ([**Report a vulnerability**](https://github.com/flaggr-dev/terraform-provider-flaggr/security/advisories/new) on this repository's Security tab) or by email to **[security@flaggr.dev](mailto:security@flaggr.dev)**. Include a description of the issue, steps to reproduce it and its potential impact. We acknowledge reports within 48 hours and coordinate disclosure with you once a fix is available.

This policy covers this provider and the Flaggr platform at [flaggr.dev](https://flaggr.dev).

## Supported versions

Security fixes are released for the latest minor version of the provider.
